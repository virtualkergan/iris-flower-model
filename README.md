# iris-flowers-model
IN PROGRESS - Neural network model for predicting the species of an Iris flower based off of four measurements. Trained on Edgar Anderson's Iris flower data set. Utilizes PyTorch for machine learning applications and marimo for version control-friendly Python notebooks.

> Apply machine learning techniques to develop and train a simple classification model.

## Usage
This project is intended to be managed by the `uv` package manager. Run the following commands in your terminal to install the latest version of `uv`:   
```
cd ~
curl -LsSf https://astral.sh/uv/install.sh | sh
```
Clone this repository and navigate to its root directory. Run the following command to initialize a matching virtual environment for the repository:
```
uv sync
```
Run the following command to start and open a local `marimo` server:
```
marimo edit
```
